# MaSyMoS 1.x masymos-cli

**This repository is kept for the record.** It holds the 1.x code exactly as it was published, so that work citing it stays
readable, and it is not developed any further.

**Development continues in [https://github.com/MaSyMoS/masymos](https://github.com/MaSyMoS/masymos)**, the monorepo of the modernised
MaSyMoS 2.0, which contains [modern/masymos-cli](https://github.com/MaSyMoS/masymos/tree/master/modern/masymos-cli) - the command line interface, now backed by the REST service - beside
the shared core and the Neo4j storage.

The original README of this repository is preserved unchanged in
[README-legacy.md](README-legacy.md).
