# MaSyMoS 1.x masymos-cli

**This repository is kept for the record.** It holds the MaSyMoS 1.x code exactly as it was published, so that work citing it
stays readable, and it is not developed any further.

**Development continues in [MaSyMoS/masymos](https://github.com/MaSyMoS/masymos)**, the monorepo
of the modernised MaSyMoS 2.0. What replaces this module is
[modern/masymos-cli](https://github.com/MaSyMoS/masymos/tree/master/modern/masymos-cli): the command line interface, now backed by the REST service.

The original README of this repository is preserved unchanged in
[README-legacy.md](README-legacy.md).
